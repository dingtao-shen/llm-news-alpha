# 基线数据链路检验（2026-10-23，与 baseline_alpha158_lgb 同一数据集）

- 训练集 455,510 行 × 157 个特征，特征 NaN 占 0.003%（最高 ROC60 0.2%），标签 NaN 0；测试集 485,997 行，标签 NaN 0.037%，标签日标准差 2.46%。
- 教科书因子对同一标签（开盘到开盘）的日均 Rank IC，2020–2023，1,006 个交易日：

| 因子 | Rank IC | ICIR |
| --- | ---: | ---: |
| 昨日收益（短期反转） | −0.0181 | −0.082 |
| 5 日收益 | −0.0161 | −0.071 |
| 20 日动量（跳过最近 1 天） | +0.0011 | +0.005 |
| 20 日波动率 | −0.0027 | −0.010 |
| **LightGBM（Alpha158 基线）** | **+0.0058** | **+0.054** |

- LightGBM Rank IC 按年：2020 0.0121、2021 −0.0002、2022 0.0104、2023 0.0009。
- 结论：数据链路正常（短期反转的负 IC 清楚可见），基线弱是模型本身的问题：验证集 l2 在第 5 轮就不再下降（早停），
  当前超参下 LightGBM 几乎只学到常数。模块 5 调参时应以验证年 Rank IC 为目标重调（更小学习率、更强正则、更多轮），
  并把"昨日收益反转"这一单因子作为另一个基线列进表 B。
